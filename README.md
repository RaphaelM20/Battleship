# Battleship

A fully playable Battleship game built with vanilla JavaScript. [Live Demo](https://raphaelm20.github.io/Battleship/)

![Battleship Preview](https://res.cloudinary.com/zrc0epiv/image/upload/v1788890389/battleship-preview_airamm.jpg)

## Features

- Interactive ship placement before the game starts
- Randomized AI opponent with turn-based attacks
- Win/loss detection with game reset
- Fully tested with Jest

## Tech Stack

- JavaScript
- HTML, CSS
- Jest (unit testing)
- Webpack

## Running Locally

```bash
git clone https://github.com/RaphaelM20/Battleship
cd Battleship
npm install
npm start
```

Visit `http://localhost:8080` to play.

## Running Tests

```bash
npm test
```
